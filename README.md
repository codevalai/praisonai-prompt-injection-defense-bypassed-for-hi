# PraisonAI Injection Defense Hardened\n\nProduction-grade multi-agent guardrail orchestrator built to prevent prompt injection and authority spoofing in generative AI systems.\n\n## Overview\nLarge Language Models are vulnerable to prompt injections, authority spoofing, and boundary manipulation. This system introduces an active multi-agent defense architecture that screens and sanitizes prompts prior to execution.\n\n## Architecture\n1. **Boundary Validator**: Inspects formatting boundaries and delimiters.\n2. **Intent & Authority Screener**: Detects override commands and fake system prompts.\n3. **Consensus Aggregator**: Computes multi-stage risk scores before delegating to downstream services.\n\n## Quick Start\n```bash\nnpm install\nnpm run build\nnpm test\nnpm start\n```
